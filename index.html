About this site

This site does a daily fetch of the Socrata data catalogs for the city of Chicago, Cook County, and the state of Illinois, and then uses the Socrata API's /views endpoint to fetch metadata for each of the datasets (mostly, the current row count).

I made this site because the current public data portals don't make it easy to know if a dataset is worth clicking through, so I found it useful to compile their catalogs as a table that showed metrics such as number of cells/columns, frequency of updates, and number of views and downloads. Leave questions/issues at the Github repo. Check out my other Chicago public data site, an interactive map and database of Chicago traffic crashes and fatalities: Crash Stop Chicago.
